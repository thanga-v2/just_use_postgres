How to preserve the state ?

Using volumes.


docker run -it  --entrypoint=bash -v "$(pwd)/test:/thanga/" python:3.13.11-slim

-v "$(pwd)/test:/thanga/" -> mounts whatever the data available in  the test directory to thanga directory inside the container.
