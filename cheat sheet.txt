-- LIST TABLES
\dt                    -- All tables in current schema
\dt *.*                -- All tables in all schemas
\dt public.*           -- Tables in public schema only

-- DESCRIBE STRUCTURE
\d orders              -- Full structure: columns, types, constraints, indexes
\d users               -- Same for users table
\d+ orders             -- Extended info: storage, compression, description

-- DATABASE NAVIGATION
\l                     -- List ALL databases on server
\c de_bootcamp         -- Connect/switch to database
\conninfo              -- Show current connection details (user, host, db)

-- SCHEMA & PERMISSIONS  
\dn                    -- List schemas (public, pg_catalog, etc.)
\du                    -- List users/roles
\dp orders             -- Show table permissions (who can read/write)

-- UTILITY
\timing on             -- Show query execution time (CRITICAL for learning)
\?                     -- Help for ALL psql commands (overwhelming, use sparingly)
\q                     -- Quit psql (or Ctrl+D)

How to switch between or connect to the databases ?


\l or select datname from pg_dataabse;  -> to list the databases.

\c Database_Name to switch to the database

thanga=# \c coffee_chain

You are now connected to database "coffee_chain" as user "thanga".
coffee_chain=# 

we can also include -d in the docker to connect to the data base 

docker exec -it postgres psql -U postgres -d coffee_chain
